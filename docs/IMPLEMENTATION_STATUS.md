# حالة تنفيذ ClassTrack

## منفذ في الكود

واجهات Android عربية للمدرس والطالب، Auth بالأدوار واستكمال الحساب، الفصول والأكواد والعضويات، موقع المقدمة، جلسة 120 ثانية بوقت سيرفر، Punch-In، خمسة أسئلة داخل التطبيق وحل وتسليم، قواعد وقت وعضوية ومسافة وتكرار، مفاتيح إجابة خاصة، تصحيح تلقائي عند المدرس، متابعة مباشرة وسجل وإجماليات وأحداث محاولات وتثبيت الغياب أثناء المراجعة.

## التحقق المحلي

- Firestore Emulator: **34 اختبار قواعد نجح**.
- Flutter: **9 اختبارات نجحت**.
- التحليل الثابت: اجتاز دون أخطاء أو تحذيرات في المراجعة المسجلة.

## Firebase الحقيقي

أكد المالك نشر القواعد والفهرس وتفعيل Auth، ونجحت 11 حالة تحقق فعلية تشمل الوضعين والرفض والتكرار وسرية المفتاح والتصحيح والفهرس وانتهاء الوقت وتثبيت الغياب. التفاصيل في LIVE_BACKEND_TEST.md. الإحداثيات مصطنعة، وليست اختبار GPS فعليًا.

## ملف التثبيت

نجح بناء APK Release شامل لمعماريات armeabi-v7a وarm64-v8a وx86_64، بحد أدنى Android 7.0 / API 24. تحقق APK Signature v2 نجح، وسلامة ZIP/CRC نجحت. نسخة العرض موقعة بمفتاح debug وليست إصدار متجر.

## ما يحتاج تجربة الفريق

- تجربة جهازين ونتائج GPS الفعلية ثم الديمو الحي/المسجل.

## بيانات الفريق

الأسماء الخمسة أضيفت بنفس الكتابة المقدمة. الأرقام الجامعية والأدوار/المساهمات فارغة لاستكمالها لاحقًا بمعرفة الفريق حسب طلبه.

لا ميزات Bonus، ولا Storage أو Functions أو فوترة.
